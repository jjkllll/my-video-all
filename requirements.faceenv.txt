# =============================================================================
# .faceenv —— Python 3.11 隔离环境依赖
#
# 覆盖以下脚本：
#   python/face_detect.py        人脸时间段检测（InsightFace + onnxruntime）
#   python/transcribe.py         语音转字幕（faster-whisper）
#   python/remove_vocals.py      去人声（Demucs）
#   python/detect_subtitles.py   字幕区域检测（OpenCV 启发式）
#   python/text_detect.py        字幕文本检测（ONNX Runtime + PP-OCR）
#
# 安装：
#   conda create -p .faceenv python=3.11 -y
#   .faceenv/bin/python -m pip install -r requirements.faceenv.txt
#   # insightface 单独安装，见下方说明
#   .faceenv/bin/python -m pip install --no-deps insightface==2.1
#
# 注意：
#   - insightface 依赖 onnxruntime / opencv-python，会与下方的 GPU 版
#     onnxruntime-gpu 及 headless 版 OpenCV 冲突，因此未列入本文件，
#     需在所有依赖装完后用 --no-deps 单独安装（见上面命令）。
#   - 无需 GPU 时，把 onnxruntime-gpu 换成 onnxruntime==1.20.2 即可。
#   - 首次运行会从 HuggingFace 下载检测 / 识别 / Whisper 模型，
#     下载位置见 python/.insightface、python/.whisper-models、python/.demucs-models。
#   - 系统需可用的 C++ 编译工具链（insightface 为源码包，安装时会编译扩展）。
# =============================================================================
